# Legendary Online

Legendary Online 是一个面向 Java 游戏服务端学习和求职展示的多人 2D ARPG 垂直切片项目。

## 项目路线

```text
Unity 2D + C# 客户端
        |
        | TCP + Protocol Buffers
        v
Java 21 + Netty 游戏服务端
        |
        +-- Session
        +-- Scene Tick
        +-- 服务端权威移动和战斗
        +-- 状态广播
```

## 就业目标

本项目不仅用于学习 Java 游戏服务端，也用于形成符合当前招聘市场要求、可在面试中演示和复盘的项目作品集。目标方向是 Java 游戏服务端工程师，同时覆盖 Java 后端岗位可迁移的网络、并发、数据和工程化能力。

结合 Boss 直聘、拉勾网、前程无忧及企业招聘页公开 JD 的共性要求，项目重点覆盖：

- Java 基础、并发编程、JVM 和代码质量。
- TCP/IP、Socket、Netty、拆包粘包、心跳和连接生命周期。
- 游戏服务端场景循环、命令队列、服务端权威逻辑和状态同步。
- MySQL、Redis、消息队列及其与实时主链路的边界。
- Linux、Maven、Git、Docker、日志、测试和性能分析。
- 系统设计、故障定位、性能验证和技术文档表达。

项目中的每项能力都必须对应代码位置、测试、运行命令或可复现的观察结果；尚未实现或尚未验证的能力不写成已完成。

项目主线从多人服务端工程重新建立，最终客户端采用 Unity 2D + C#。

## 第一阶段目标

先建立 Maven 多模块工程和可启动的 Netty 服务端骨架，再完成 Protobuf 协议、Session、场景 Tick、服务端权威移动和战斗闭环。

目标验证命令：

```text
mvn clean test
```

服务端启动后应输出：

```text
Game server started
Netty listening on port 9000
```

## 发展边界

第一阶段不引入微服务，不提前接入 Flink，也不提前写入未经压测验证的性能指标。主线先完成两个客户端登录、同场景移动同步、服务端权威战斗、断线清理和重连恢复。
