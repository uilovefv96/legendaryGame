# 功能说明

## 1. 文档目的

组件说明回答“Netty、Protocol Buffers、Redis 是什么以及如何使用”；功能说明回答“登录、Session、移动和战斗在本项目中如何设计和实现”。

组件是基础设施，功能是业务流程，两类文档分开维护。

## 2. 功能文档模板

后续每个核心功能创建一篇文档：

```text
docs/功能说明/<功能名称>.md
```

推荐章节：

1. 功能目标。
2. 学习目标。
3. 前置知识。
4. 业务流程和时序图。
5. 线程模型。
6. 协议消息。
7. 模块和代码入口。
8. 正常流程。
9. 非法输入和失败流程。
10. 测试清单。
11. 实验结果。
12. 复盘问题。

## 4. 移动同步功能学习卡示例

### 学习目标

- 理解客户端输入意图和服务端权威坐标的区别。
- 理解网络线程和场景 Tick 线程的边界。
- 理解输入序号的作用。
- 理解位置广播和场景快照的关系。

### 设计问题

- 客户端能不能提交最终坐标？
- 移动命令在哪个线程执行？
- 速度和地图边界如何校验？
- 输入序号倒退或重复时如何处理？
- 广播是在 Tick 内直接发送，还是先收集事件？

### 测试清单

- 正常移动。
- 未登录移动。
- 方向未指定。
- 输入序号倒退。
- 速度超限。
- 越过地图边界。
- 两个玩家同时移动。
- 断线后队列中仍存在移动命令。

### 复盘问题

- 为什么最终坐标不能由客户端提交？
- 为什么移动不能直接在 Netty Handler 中执行？
- 为什么需要输入序号？
- 为什么位置广播不能替代服务端权威状态？
