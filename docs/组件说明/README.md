# 组件说明

## 1. 文档目的

本目录用于记录项目中引入的基础组件，帮助学习者理解组件本身，以及它在 Legendary Online 中为什么这样使用。

组件文档不是 API 手册，也不是依赖清单。每篇文档都需要回答：

- 这个组件解决什么问题？
- 它和相邻组件的边界是什么？
- 项目为什么选择它？
- 当前代码在哪里使用它？
- 关键参数和线程模型是什么？
- 常见错误是什么？
- 如何通过实验验证自己真的理解？

## 2. 文档目录

- [Netty](Netty.md)：TCP 长连接、EventLoop、Channel、Pipeline 和分帧。
- [Protocol Buffers](Protocol%20Buffers.md)：`.proto` Schema、代码生成、二进制消息体和协议兼容。

## 3. 新组件文档模板

后续引入新组件时，按以下结构创建文档：

```text
docs/组件说明/<组件名称>.md
```

推荐章节：

1. 组件定位。
2. 基础概念。
3. 为什么项目使用它。
4. 当前项目中的模块和代码入口。
5. 关键配置、生命周期和线程模型。
6. 与其他组件的边界。
7. 已实现和未实现内容。
8. 常见误区和失败案例。
9. 最小实验和验证命令。
10. 复盘问题。

## 4. 引入组件的学习流程

1. 先补充组件说明文档的基础知识和选型原因。
2. 再在项目中引入最小可运行用法。
3. 为关键配置和边界补充代码注释。
4. 添加聚焦测试或可重复实验。
5. 在文档中记录验证结果和当前限制。
6. 完成复盘后，再进入下一个组件或业务功能。

“引入依赖”不等于“掌握组件”。只有完成理解、实现、验证和复盘，才算完成该组件的学习阶段。
